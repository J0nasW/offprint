Why it's local

A 0.9 billion-parameter open model now scores 95.2 on OmniDocBench — above Gemini 3 Pro at 92.9 and GPT‑5.2 at 86.6 — and it runs on a laptop. For reading documents, on-device stopped being the compromise. Your PDFs never leave the machine, and there is no account, no quota, and no per-page bill.

How it works

01

Drop it in

One PDF, a stack of them, or a whole folder. The window is the drop target.

02

Pick a tier

Three stops from instant to most accurate, each labelled with what it actually costs.

03

Take the output

Markdown to read, JSON to build on, figures cropped out alongside.

The three stops

TierWhat runsSpeedDownload
Fast The PDF's own text layer, with Apple Vision for scanned pages 0.04–0.6 s/page none
Balanced GLM-OCR reads whatever the text layer can't describe ~4.3 s/page 1.25 GB
Best Vision finds the regions, GLM-OCR reads each one ~4.3 s/page, every page same model

Speeds are measured on an M1 Pro by the project's own harness, not estimated. Prose-only pages sit at the fast end; pages holding tables cost more, because they get a real table read rather than a guess. Balanced and Best share one download — the difference is compute, not disk. Fast needs no network at all.

What comes out

{
  "pages": [{
    "index": 0, "width": 595, "height": 841,
    "blocks": [
      { "type": "heading", "level": 1, "text": "…", "bbox": [74, 71, 447, 12.8] },
      { "type": "table", "rows": [[{ "text": "…", "colSpan": 2 }]] },
      { "type": "figure", "path": "images/p001-fig01.png" }
    ]
  }]
}

Markdown and JSON render from the same block tree, so they can't disagree. JSON keeps bounding boxes and column spans — the things Markdown has no way to say.

Details that matter

Columns read in the right order

A two-column paper is rebuilt from glyph geometry, so the columns don't interleave into fluent nonsense.

Tables stay tables

Merged cells survive into JSON. When the structure looks doubtful, the output says so instead of pretending.

Figures come with it

Charts and diagrams are cropped from the page and linked from the Markdown.

Every page routed on its own

A digital report with scanned appendices gets both halves right.

Agents can read it directly

An MCP server ships in the app: an assistant sees the outline, searches it, and reads the one section it needs — instead of swallowing 60,000 tokens.

Built for feeding models

Word, character and token counts, plus chunks cut by section that carry their heading trail — not a fixed window that cuts sentences in half.

Contents pages become outlines

A table of contents is a nested list of pointers, not a table, and it comes out as one.
