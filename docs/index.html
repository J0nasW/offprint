Dense PDFs, turned into Markdown you can actually use.

Offprint reads a paper the way you do — columns in order, headings as headings, tables as tables — and writes it out as clean Markdown and structured JSON. On your Mac, without sending a page anywhere.

macOS 26 or later, Apple silicon. Free, open source, no account.

Most PDF converters read a two-column paper wrong.

They take the text in the order the file happens to store it, which on a two-column page interleaves the columns. What comes out is fluent, plausible, and says something the paper never said.

Offprint ignores that order entirely. It finds the gutter by looking at where the glyphs actually sit, keeps a full-width title whole, and reads the left column to the bottom before starting the right one.

The same geometry finds tables by their empty columns, so a results table survives as a table instead of becoming a paragraph of numbers.

A contents page becomes an outline

Not a two-column table. Entries keep their page numbers and nest by section number, so you can navigate what you extracted.

Maths comes out as LaTeX

$\mathcal{A}=\{A_{1},\dots,A_{n}\}$, not a row of broken glyphs — and the preview renders it as 𝒜={A₁,…,Aₙ}.

Running headers are dropped

A journal repeats its title and DOI on all fifteen pages. That belongs to the paper, not to what you asked for.

When a table looks wrong, it says so

A mis-split table still renders as valid Markdown, so nothing downstream can catch it. Offprint flags the ones it could not verify.

Seconds per page, measured on an M1 Pro by the project's own test harness. A 125-page report takes about 40 seconds on Fast.

Three settings, and honest numbers for each.

Fast needs no download and no network, and handles most born-digital PDFs completely — its text is exact, because it comes from the file rather than from a guess about pixels.

The other two run a 0.9-billion-parameter document model on your own GPU. It is worth the wait for scans, for handwriting, and for pages where the maths matters more than the minutes.

An assistant can read your PDFs without swallowing them.

Offprint speaks the Model Context Protocol, so Claude Code, Claude Desktop or any MCP client can open a document on this Mac.

A 125-page report is about 64,000 tokens. Handing that back in one call spends most of an agent's context answering something one section would have answered, so the tools are built the other way round: read the outline, search it, then pull the part you need.

claude mcp add offprint -- \
